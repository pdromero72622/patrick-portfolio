# AI-Assisted Development

This project was built using an AI-assisted development workflow.

The purpose was not to delegate development blindly, but to use AI as a reasoning, debugging, and implementation partner.

## Tools

Primary AI tool:

- ChatGPT

Additional AI tools used in professional development work include:

- Claude

## Development Approach

The workflow generally followed:

```text
Understand the requirement
        ↓
Provide context to AI
        ↓
Explore implementation options
        ↓
Review generated suggestions
        ↓
Implement selectively
        ↓
Run the application
        ↓
Test behavior
        ↓
Refine based on actual results
